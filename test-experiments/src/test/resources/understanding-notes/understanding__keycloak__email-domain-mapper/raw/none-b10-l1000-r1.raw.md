Keycloak. Mappers live in services/src/main/java/org/keycloak/protocol/oidc/mappers/ — imitate HardcodedClaim.

Extend AbstractOIDCProtocolMapper and implement OIDCIDTokenMapper, OIDCAccessTokenMapper, UserInfoTokenMapper, TokenIntrospectionTokenMapper. The base transform*Token methods already consult OIDCAttributeMapperHelper.includeInIdToken/AccessToken/UserInfo/Introspection, so you only override setClaim(IDToken, ProtocolMapperModel, UserSessionModel, KeycloakSession, ClientSessionContext): read token.getEmail(), take the part after '@', return silently if null or no '@', else OIDCAttributeMapperHelper.mapClaim(token, model, domain). AccessToken extends IDToken, so that one method covers every token.

getId()="oidc-email-domain-mapper"; getDisplayCategory()=TOKEN_MAPPER_CATEGORY; build the static config list with OIDCAttributeMapperHelper.addTokenClaimNameConfig(list) + addIncludeInTokensConfig(list, YourClass.class).

Two registrations, both required: services/src/main/resources/META-INF/services/org.keycloak.protocol.ProtocolMapper (provider-id resolution) and OIDCLoginProtocolFactory.initBuiltIns() via builtins.put(name, model) — that map is what a fresh realm is offered. Leave default client scopes alone.
