Mappers live in services/src/main/java/org/keycloak/protocol/oidc/mappers/. Copy a simple sibling there (UserSessionNoteMapper): extend AbstractOIDCProtocolMapper, implement OIDC{ID,Access}TokenMapper, UserInfoTokenMapper, TokenIntrospectionTokenMapper. The base transform*() methods already consult OIDCAttributeMapperHelper.includeIn*, so the 4 admin switches work once getConfigProperties() calls OIDCAttributeMapperHelper.addIncludeInTokensConfig(list, getClass()). Override setClaim(IDToken,...): read token.getEmail(), take the text after '@', add nothing if null/no '@'/empty. Display category = TOKEN_MAPPER_CATEGORY; getId() = oidc-email-domain-mapper.
