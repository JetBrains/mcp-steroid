## Milestone 1: Extract mcp-core (Foundation)

All other modules depend on mcp-core. This milestone creates the module, moves protocol + registry files out of ij-plugin, replaces IntelliJ Logger with SLF4J, and verifies ij-plugin still compiles and passes tests.

### Step 1: Create mcp-core module and extract MCP protocol/registry files
- **Status:** pending
- **Skill:** default
- **Input specs:** [mcp-core]
- **Depends on:** (none)
- **Parallel with:** (none)
- **Agent instructions:**
  1. Add `:mcp-core` to `settings.gradle.kts`
  2. Create `mcp-core/build.gradle.kts` with dependencies: `kotlinx-serialization-json:1.9.0`, `kotlinx-coroutines-core:1.9.0`, `slf4j-api:2.0.+`. Apply `kotlin("jvm")` and `kotlin("plugin.serialization")` plugins. No IntelliJ Platform dependency.
  3. Move all `.kt` files from `ij-plugin/src/main/kotlin/com/jonnyzzz/mcpSteroid/mcp/` to `mcp-core/src/main/kotlin/com/jonnyzzz/mcpSteroid/mcp/` — keep the package name `com.jonnyzzz.mcpSteroid.mcp` unchanged.
  4. Also move `McpProgressReporter.kt` from `ij-plugin/src/main/kotlin/com/jonnyzzz/mcpSteroid/server/` to `mcp-core/src/main/kotlin/com/jonnyzzz/mcpSteroid/mcp/` (update package to `com.jonnyzzz.mcpSteroid.mcp`).

### Step 6: Write HTTP transport integration tests
- **Status:** pending
- **Skill:** default
- **Input specs:** [mcp-http]
- **Depends on:** Step 2
- **Parallel with:** Step 7
- **Agent instructions:**
  1. In `mcp-http/src/test/kotlin/`, create integration tests using `ktor-server-test-host`.
  2. Tests to write (per spec):
     - Initialize handshake: POST `initialize` → verify `InitializeResult`, protocol version header
     - Tool lifecycle: register tools → `tools/list` → `tools/call` → verify results
     - Resource lifecycle: register resources → `resources/list` → `resources/read`
     - Prompt lifecycle: register prompts → `prompts/list` → `prompts/get`
     - Session management: creation, reuse, stale notification, DELETE termination
     - Error handling: invalid JSON, unknown method, invalid params → JSON-RPC error codes
     - CORS: OPTIONS preflight → verify headers
     - Batch requests: JSON array → batch response
  3. Each test creates a fresh `McpServerCore` with test tools/resources, installs `McpHttpTransport`, and exercises the HTTP API.
  4. Run `./gradlew :mcp-http:test`.
